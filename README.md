# govuk-node-express-nunjucks-examples

Use four spaces for indentation. Prettier formats supported project files, and
ESLint enforces Prettier formatting for JavaScript and TypeScript. EditorConfig
sets the same indentation defaults for new files.

- `npm run format` formats project files.
- `npm run lint:fix` fixes lint and formatting issues in JavaScript and TypeScript.
- `npm run check` checks formatting and lint rules; run it before committing.

In VS Code, install the recommended ESLint and Prettier extensions to enable
formatting on save. Generated output, dependencies, and the npm lockfile are
excluded from formatting; npm manages the lockfile's layout.
